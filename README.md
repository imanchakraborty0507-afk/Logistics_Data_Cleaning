
# Logistics Data Collection and Cleaning Using Python

## 1. Project Overview
This project focuses on collecting, inspecting,
and cleaning logistics data using Python.

## 2. Dataset
Brazilian E-Commerce Public Dataset by Olist.

Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## 3. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib

## 4. Project Objectives
- Collect public logistics data.
- Explore and understand the dataset.
- Identify missing values.
- Remove duplicate records.
- Normalize date and text formats.
- Generate a cleaned dataset.

## 5. Project Structure
- data/: Dataset storage
- src/: Python source code
- reports/: Data quality reports

## 6. How to Run

Install dependencies:

pip install -r requirements.txt

Run data collection:

python src/data_collection.py

Run data cleaning:

python src/data_cleaning.py

## 7. Expected Outcomes
A cleaned dataset with standardized
formats and improved data quality.
